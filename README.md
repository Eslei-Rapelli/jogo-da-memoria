# Jogo da Memória da Família

## Subir no GitHub
1. Crie um repositório novo (ex.: jogo-memoria).
2. Envie todos os arquivos mantendo a pasta `public` (Add file > Upload files, arrastando a pasta).

## Publicar no Render
1. Render > New > Web Service > conecte o repositório.
2. Runtime: Node. Build Command: `npm install`. Start Command: `npm start`. Plano: Free.
3. Quando terminar, abra o link `https://SEU-APP.onrender.com`.

## Observações
- No plano gratuito o Render "dorme" após ~15 min parado; o primeiro acesso pode levar cerca de 1 minuto.
- As salas ficam na memória do servidor: se ele reiniciar ou dormir sem ninguém conectado, as salas somem.
- Instalar no celular: Android (Chrome) usa o botão "Instalar app"; iPhone (Safari) em Compartilhar > Adicionar à Tela de Início.
